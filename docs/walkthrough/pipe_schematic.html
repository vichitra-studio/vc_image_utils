The vc::pipe system

One assembly line for image processing. Stations do the work, parcels carry the data, and a foreman checks every connection before a single pixel moves. Typed slots at the authoring edge, erased names inside — the one boundary the whole design turns on.

The parts

i_pipeabstract base
  • const stage_name& name() const // per-instance
  • virtual const char* kind() const = 0 // per-type
  • virtual void declare(contract_builder&) const = 0
  • virtual void process(vc_pipe_context&) const = 0
  • protected: i_pipe(stage_name)
One processing station. name() is its address in a graph; kind() is its type. declare() posts its contract; process() does the work. Both const — a pipe is stateless per run.
slot<T>authoring · compile-time
  • template<T> struct slot { string_view name; }
  • // declared once per stage:
  • static constexpr slot<vc_image> rgb{"rgb"}
The label a stage prints on a chute: a name bonded to its payload type. Lives only at the authoring edge — the instant it crosses into the framework it is lowered (name kept, T erased). Never stored.
stage_portwiring currency
  • stage_name stage;  slot_name slot
  • stage_port(stage, slot<T>) // lowers T
  • stage_port(stage, slot_name) // from a name
  • bool operator==(…);  size_t hash()
A graph coordinate: which slot on which stage. THE run-time currency — run() keys its maps by it, and connect() lowers each (stage, slot<T>) into one internally. Built from a typed slot<T> or a plain name (the config path).
vc_pipe_packetvalue · type-erased
  • template<T> explicit vc_pipe_packet(T) // sink
  • template<T> const T& get() const // throws on mismatch
  • bool has_value() const
  • const type_info& type() const
  • private: std::any value_
A sealed parcel. Holds any one payload — image, matrix, a plain double — and remembers its type so a stage can unbox it safely.
vc_pipe_contractframework
  • template<T> void add_input_slot(slot<T>)
  • template<T> void add_output_slot(slot<T>)
  • type_index input_slot_type(name) // throws
  • type_index output_slot_type(name) // throws
  • vector<slot_name> input_slot_names() / output_slot_names()
  • private struct slot_decl { name; type }
The signs a stage posts — but a stage never holds this contract: declare() is handed a narrow write-only contract_builder view (add_*_slot only). The full contract, with its name-keyed type lookups, stays framework-internal for validate()/run() (§12.6). Lookups throw on an undeclared slot (exceptions-only) — so validate() never branches on not-found. Type layer live · data layer (image spec) later
vc_pipe_contextper-run tray
  • // author-facing (typed slot<T>)
  • template<T> const T& get_input(slot<T>) const
  • void set_output(slot<T>, vc_pipe_packet)
  • // runner-facing (whole-map handoff)
  • explicit vc_pipe_context(unordered_map<name, packet>)
  • unordered_map<name, packet> take_outputs() &&
  • private: name-keyed lowering + unordered_map inputs_, outputs_
The tray for one run of one stage. The surface splits by audience and no name-keyed method is public: the author reads inputs / writes outputs through typed slot<T>; the runner injects inputs through the map constructor and harvests through take_outputs(), working name-keyed on plain maps it owns. Input & output stay separate namespaces.
vc_pipelineorchestrator · the belt + foreman
  • stage_name add(unique_ptr<i_pipe>) // takes ownership; returns the stage's own name()
  • template<Tout,Tin> void connect(stage_name, slot<Tout>, stage_name, slot<Tin>) // wire output slot → input slot
  • void validate() const TODO(you) — assembly-time type check
  • unordered_map<stage_port, vc_pipe_packet> run(unordered_map<stage_port, vc_pipe_packet>) const TODO(you)
  • private struct connection { stage_port from; stage_port to }
  • private: vector<unique_ptr<i_pipe>> stages_;  vector<connection> connections_
Assemble → validate → run. Holds pipes generically as i_pipe; every wire is spelled through a stage's typed slots:: members, which connect() lowers to a stage_port internally — the string coordinate stays the runtime-composition currency a CLI or config file can compose, but authors never spell it. run() is the map variant: inject the open inputs, execute in order, harvest the open outputs.
vc_passthrough_stagestage
  • in "in" : vc_image → out "out" : vc_image
Worked reference — fully implemented. Copies its input through unchanged. The template every other stage follows. kind() == "passthrough".
vc_grayscale_stagestage · TODO
  • in "rgb" : vc_image → out "grey" : vc_image
image → image. A plain Transform. declare() / process() are yours to write.
vc_mean_brightness_stagestage · TODO

image → scalar. The output is not an image — the exact case a plain apply(image)→image can't express. This is why the whole design exists.

The wiring, in two phases

Worked on a real chain — grayscale → mean_brightness (image → image → a single number).

1Assembly & validationno pixels move — declarations only
1
const auto grey = pipe.add(make_unique<vc_grayscale_stage>("grey"));

Stations mounted on the belt. Each stage carries its own name; add() returns it for typo-safe wiring. (Same for "mean".)

2
pipe.connect(grey, grayscale::slots::grey, mean, mean::slots::image);

Wire grayscale's "grey" output slot to mean's "image" input slot. Each wire is spelled through the stage's typed slots:: member; connect() lowers each (stage, slot<T>) to a stage_port internally.

3
pipe.validate();

Foreman calls every stage's declare(), then checks each connection by comparing the two declared types — no packet exists yet.

grey.grey : vc_image ──▶ mean.image : vc_image ✓ match
if instead mean.mean : double ──▶ grey.rgb : vc_image ✗ throws — line stops
2Runthe map variant — inject, execute, harvest
1
auto out = pipe.run({ {{grey, slots::rgb}, vc_pipe_packet{move(img)}} });

Feed the source onto the graph's open input — grey's "rgb" (nothing wired feeds it). The map is a sink: move avoids a deep copy.

tray · grayscale.process(ctx)
in "rgb"vc_image reads ▸ writes out "grey"vc_image
▼   grey's "grey" output routes to mean's "image" input (per the connection)
tray · mean_brightness.process(ctx)
in "image"vc_image reads ▸ averages ▸ writes out "mean"double
2
const vc_image& img = ctx.get_input(slots::image);

Inside process(), the typed slot deduces vc_image and unboxes the packet. In a validated graph this any_cast is guaranteed to succeed — the types were already checked in phase 1.

3
double b = out.at({mean, slots::mean}).get<double>();

Harvest the graph's open output — mean's "mean" slot, keyed by its stage_port in the returned map. A non-image parcel rode the same belt end to end.
